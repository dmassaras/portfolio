ARCHITECTURE PORTFOLIO WEBSITE

Άνοιγμα:
1. Αποσυμπιέστε το ZIP.
2. Ανοίξτε το αρχείο index.html με Chrome/Edge/Firefox.

Δομή:
- index.html: κεντρική σελίδα
- assets/style.css: εμφάνιση
- assets/script.js: μενού και lightbox
- assets/images/: εικόνες του portfolio
- assets/Maria_Theodora_Metsi_Portfolio.pdf: πλήρες PDF

Σημείωση για Google Sites:
Το Google Sites δεν εισάγει απευθείας ολοκληρωμένα ZIP/HTML sites. Το πακέτο λειτουργεί ως έτοιμο responsive website και ως πλήρης οδηγός/πηγή περιεχομένου για χειροκίνητη μεταφορά σε Google Sites. Μπορεί επίσης να δημοσιευθεί αυτούσιο σε GitHub Pages, Netlify ή άλλο static hosting.
